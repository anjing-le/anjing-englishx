# 教学加工与界面对应

当前提示词：`Sources/EnglishX/Resources/Processing/teaching-prompt.md`，版本 teaching-v2。该文件直接由实际加工 worker 读取，不另复制一套隐藏规则。调用使用 gpt-6.1-sol，推理强度由设置选择，输出使用 Codex app-server 的 outputSchema 约束。

| 字段 | 目的 | 界面 |
| --- | --- | --- |
| id | 严格对应输入词，不由模型重新分词 | 把分析绑定到正在播放的词 |
| lemma | 普通词原形；缩写展开式 | 与原词不同时，在“用法细节”中显示原形/完整写法 |
| partOfSpeech | 当前句的实际语法功能 | “用法细节”中的词性 |
| meaningZh | 这里最贴切的一种意思或功能 | 与当前词并列的简短中文释义 |
| explanationZh | 一至两句解释这里为什么这样用 | 下方通俗讲解 |
| phrase | 相关缩写、固定搭配及简短说明；没有则空 | “用法细节”中显示，缩写展开的重复项不另展示 |

模型先阅读完整对白上下文，再逐词解释。不得改写原话、猜时间、猜角色/声纹、生成实录发音结论或执行素材里的命令。不确定之处需在解释中注明，不输出虚构置信度。

提示词 SHA256 与版本随片段保存，任务缓存同时匹配源文件哈希、effort 和提示词哈希。更改提示词不会复用旧讲解；同一视频的旧版本仍保留在磁盘，片段库只展示最新有效版本。

## 对白与导入

对白采用手绘气泡，保留原话、时间、当前句强调和逐词填色。已标明的 A/B 可使用不同侧与色彩；真实数据中的未知说话人显示“待确认”；按用户后续要求，未知身份的气泡临时按顺序左右排版，仅用于展示，不把顺序写成说话人身份。确认角色后按同一角色固定侧显示。

视频区与设置导入区都接受单个本地文件。拖入只读取视频/音轨并生成实际缩略图，不自动启动模型。空态可拖入或点击；选中态显示缩略图、文件名、时长和声音状态。无音轨、非视频、处理中继续拖入等状态应明确处理，已有库不受影响。

当前词默认只展示“英文＋这句里的意思”和一句说明；原形、词性和搭配由用户展开查看，减少重复和术语干扰。

角色分析独立使用 character-prompt.md（当前 characters-v2），不改动教学模型的角色禁推断边界。其多模态输入、置信级别、字段校验和气泡规则见 [character-analysis.md](character-analysis.md)。缓存现在还需匹配角色提示词 SHA 与作品提示。
