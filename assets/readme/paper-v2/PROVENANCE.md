# EnglishX 纸张蜡笔配图

本组使用内置 image_gen 制作，参考本机 cs-tool-x 的纸张铅笔功能图和 EnglishX 官网原有的胶片主视觉。完整提示词见各图同名 `.prompt.txt`；正方形品牌图的重排提示另存为 `.edit.prompt.txt`。独立放在 paper-v2，保留此前素材。

- `00-brand.png`：无字品牌主视觉，中文版、英文版 README 与官网挂牌共用。
- `01-overview.png`：片段收藏、对白回放、词句理解、校对保存总览。
- `02-library.png`：片段库及同一学习工作区。
- `03-playback.png`：点击句子回放、倍速与当前词跟随。
- `04-context.png`：单词和短语的语境含义及发音参考。
- `05-review.png`：修改原话与逐词时间，更新分析并保留旧版。

所有内容为原创说明插画，不是真实截图、实际转写数据、运行结果或准确性证据。海岸、视频缩略图和示例对白均为通用原创演示，不包含学习库媒体、角色、个人图标、私人数据或凭据。识别和时间仍为估计，自动讲解需核对；现有 README 的处理、模型数据发送与本地预览说明保留。此次用户明确要求延用 cs-tool-x 的插画风格，生成的新图不冒充项目原计划等待的用户截图。

原图为 PNG。官网使用同一原图派生的质量 92 WebP；功能图保持 2:1 完整画幅。网站负责牌体、边框、挂绳、翻转与投影。

## 英文版配图

`01-overview.en.png` 至 `05-review.en.png` 使用内置 image_gen 对中文原图定向替换文字，保留原有 1774×887 画幅、构图、纸纹和笔触。完整英文替换词与约束见各图 `.en.prompt.txt`。无字主视觉 `00-brand.png` 继续共用。英文 README 与中文版保持相同图序、360 宽主视觉、100% 宽总览及四张功能图；保留原有英文正文、来源/准确性说明和 Star 图。
